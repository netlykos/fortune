# Web App for fortune

This is a web application for the fortune project.

## Setup

Run the below a one time only activities to add the entries in ``package.json``

```sh
npm install mithril
npm install --save-dev @types/mithril
npm install --save-dev typescript
npm install --save-dev vite
```
